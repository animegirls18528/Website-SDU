# ระบบจัดเก็บเอกสารอิเล็กทรอนิกส์ (งานระบบกองคลัง - EDMS / Website-SDU)

## ระบบนี้คืออะไร 
**ตู้เก็บเอกสารของกองคลัง** แต่เป็นตู้ในคอมพิวเตอร์ — เอกสารกระดาษที่สแกนแล้ว (ฎีกา ใบเสร็จ สัญญา ฯลฯ) ถูกเก็บเป็นไฟล์ PDF พร้อม "ป้ายชื่อ" ที่บอกว่าเอกสารนี้คืออะไร ลงวันที่เท่าไร อยู่แฟ้มไหน และเก็บต้นฉบับกระดาษไว้ที่ไหน แล้วระบบช่วยตั้งแต่ **สแกน → เก็บ → ค้นหา → ตรวจสอบ → ยืม-คืนต้นฉบับ → ทำลายเมื่อครบอายุ** พร้อมกันคนไม่เกี่ยวข้องเห็นข้อมูลส่วนบุคคล และมีประวัติว่าใครทำอะไรเมื่อไร

## 1. คำศัพท์ที่จะเจอ (อธิบายแบบคน)

| คำ | ความหมายง่าย ๆ |
|---|---|
| **เอกสาร** | 1 รายการในระบบ = 1 เรื่อง (เช่น ฎีกาเบิกค่าวัสดุ) มี **ไฟล์แนบได้หลายไฟล์** (ส่วนใหญ่คือ PDF ที่สแกน) |
| **รหัสเอกสาร** | เลขประจำเอกสาร เช่น `DOC000123` ใช้ตัวอักษรอังกฤษ ตัวเลข และ `. _ / -` ได้ ไม่เกิน 100 ตัว (เพื่อให้พิมพ์เป็นบาร์โค้ดได้) |
| **คำนำหน้ารหัส (Prefix)** | ตัวอักษรหน้ารหัส บอกประเภท เช่น `DOC` = ทั่วไป ระบบรันเลขต่อให้เอง และกำหนด "อายุการเก็บ" ตามประเภทได้ |
| **แฟ้มจัดเก็บ** | เหมือนแฟ้ม/กล่องในตู้ ไว้จัดกลุ่มเอกสาร (เช่น "ฎีกา 2569") |
| **ดัชนีเพิ่มเติม** | ช่องข้อมูลที่หน่วยงานกำหนดเอง เช่น จำนวนเงิน เลขที่ฎีกา หน่วยงาน (ชนิด ข้อความ / ตัวเลข / วันที่) ค้นหาได้ |
| **แท็ก** | คำสั้น ๆ ที่แปะเพิ่มเอง เช่น `สตง`, `งบรายได้` ไว้ค้นหา |
| **วันที่จ่ายเงิน** | วันที่ของเอกสาร ระบบใช้ **นับอายุการเก็บ** (วันที่จ่ายเงิน + จำนวนปีที่เก็บ = วันครบอายุ) |
| **อายุการเก็บ / ครบอายุ** | ตามระเบียบต้องเก็บกี่ปี (ค่าเริ่มต้น 10 ปี ตั้งตามประเภทได้) เมื่อครบแล้วเอกสารถึงขอทำลายได้ |
| **ฉบับร่าง / รอตรวจสอบ / อนุมัติแล้ว** | สถานะ "ผ่านตาตรวจแล้วหรือยัง" ของเอกสาร (ดูหัวข้อขั้นตอนงาน) |
| **QR Code** | ภาพสี่เหลี่ยมลายจุด ถ้าสแกนด้วยมือถือจะเปิดหน้ายืนยันว่าเอกสารนี้เป็นของจริงในระบบ ระบบ **ประทับ QR ที่มุมขวาล่างของทุกหน้า PDF** ให้เอง |
| **บาร์โค้ด** | แถบขีดแนวตั้ง แทนรหัสเอกสาร ใช้ยิงด้วยเครื่องยิงบาร์โค้ดแทนการพิมพ์รหัส |
| **ใบปะหน้า** | กระดาษแผ่นหน้า A4 ที่พิมพ์รหัส + QR ของเอกสารหนึ่งฉบับ วางไว้หน้าแรกของชุดเอกสารก่อนสแกน ให้ระบบรู้ว่า "ตั้งแต่แผ่นนี้เป็นของเอกสารเลขนี้" |
| **ต้นฉบับกระดาษ / ตัวจริง** | กระดาษจริงที่เก็บไว้ในห้อง/ตู้ ระบบบอกได้ว่าอยู่ที่ไหน และใครยืมไป |
| **ลายน้ำ** | ข้อความจาง ๆ พาดบนหน้าไฟล์ (เช่น ชื่อผู้เปิด วันเวลา) ไว้กันเอาไปเผยแพร่ต่อและตามรอยได้ |
| **ลายมือชื่อดิจิทัล** | "ตราประทับอิเล็กทรอนิกส์" ฝังใน PDF ถ้ามีใครแก้ไฟล์ Adobe Reader จะเตือนว่าไฟล์ถูกแก้ |
| **ข้อมูลส่วนบุคคล (PDPA)** | ข้อมูลที่ระบุตัวคนได้ เช่น เลขบัตรประชาชน เลขบัญชีธนาคาร กฎหมาย PDPA ให้ต้องระวังไม่ให้คนที่ไม่เกี่ยวข้องเห็น |
| **ยืนยันตัวตนสองขั้น (2FA)** | นอกจากรหัสผ่านแล้ว ต้องกรอก **รหัส 6 หลักจากแอปในมือถือ** (Google/Microsoft Authenticator) ต่อให้รหัสผ่านรั่วก็เข้าไม่ได้ |
| **รหัสกู้คืน** | รหัสสำรอง 10 ชุด ใช้เข้าระบบแทนรหัสจากแอปตอนทำมือถือหาย (ใช้ได้ชุดละครั้ง) |
| **SHA-256 ("ลายนิ้วมือของไฟล์")** | ค่าที่คำนวณจากเนื้อไฟล์ ถ้าไฟล์เปลี่ยนแม้นิดเดียวค่าจะเปลี่ยน ระบบใช้ตรวจว่าไฟล์ยังเหมือนตอนเก็บ และตรวจไฟล์ซ้ำ |
| **OCR** | การอ่านตัวหนังสือจากภาพสแกน เพื่อให้ค้นหาข้อความในไฟล์ได้ |
| **DPI** | ความละเอียดการสแกน ยิ่งสูงยิ่งคมแต่ไฟล์ใหญ่ (300 แนะนำ) |
| **ถังขยะ** | ที่พักเอกสารที่ถูกลบ กู้คืนได้ภายใน 30 วัน (ตั้งค่าได้) แล้วถูกลบถาวรอัตโนมัติ |
| **Token (เครื่องสแกน)** | "กุญแจ" ยาว ๆ ที่ให้โปรแกรมบนเครื่องอื่นในสำนักงานส่งไฟล์สแกนเข้าระบบโดยไม่ต้องล็อกอิน |

## 2. ใครทำอะไรได้บ้าง (บทบาท)

ผู้ใช้แต่ละคนมี 1 บทบาท ผู้ดูแลระบบกำหนดที่ ตั้งค่า › ผู้ใช้และสิทธิ์ (กำหนด "แฟ้มที่เข้าถึงได้" รายคนเพิ่มได้)

| ทำอะไรได้ | ผู้ดูแลระบบ | เจ้าหน้าที่ | ผู้ดูเอกสาร |
|---|:-:|:-:|:-:|
| ค้นหา / เปิดดูเอกสาร (ตามแฟ้มที่มีสิทธิ์) | ✅ | ✅ | ✅ |
| ดาวน์โหลดไฟล์ | ✅ เสมอ | ตามนโยบาย | ตามนโยบาย |
| เพิ่ม/แก้ไขเอกสาร อัปโหลด สแกน | ✅ | ✅ | ❌ |
| ส่งเอกสารให้ตรวจ / ขอทำลายเอกสารครบอายุ | ✅ | ✅ | ❌ |
| บันทึกที่เก็บต้นฉบับ ยืม-คืน เชื่อมโยงเอกสาร จัดการทีละหลายฉบับ (ยกเว้น อนุมัติ/ถังขยะ) | ✅ | ✅ | ❌ |
| อนุมัติเอกสาร / ตีกลับ / ย้ายลงถังขยะ / กู้คืน | ✅ | ❌ | ❌ |
| เห็นข้อมูลส่วนบุคคลแบบเต็ม | ✅ | ตามนโยบาย (ค่าเริ่มต้น ไม่เห็น) | ตามนโยบาย (ค่าเริ่มต้น ไม่เห็น) |
| รายงาน แดชบอร์ด ทำลายเอกสารตามระเบียบ ลิงก์ผู้ตรวจ ตั้งค่าระบบ จัดการผู้ใช้ สำรอง/ตรวจไฟล์ | ✅ | ❌ | ❌ |
| เปิด 2FA / ดูอุปกรณ์ที่ล็อกอิน (ของตัวเอง) | ✅ | ✅ | ✅ |
| สร้าง Token ให้เครื่องสแกนอื่น | ✅ | ✅ | ❌ |

> ระบบตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ทุกครั้ง การซ่อนปุ่มในหน้าจอเป็นแค่ความสะดวก ไม่ใช่ตัวกันสิทธิ์

## 3. เมนูทั้งหมดอยู่ตรงไหน

เมนูซ้ายมือ (บนมือถือกดปุ่ม ☰) — แต่ละคนเห็นเท่าที่มีสิทธิ์

| เมนู | ไว้ทำอะไร | ใครเห็น |
|---|---|---|
| แดชบอร์ดผู้บริหาร | ภาพรวมจำนวนเอกสาร กราฟ ประวัติการใช้งาน | ผู้ดูแล |
| คลังเอกสาร | ค้นหา เปิดดู จัดการเอกสารทั้งหมด (หน้าหลัก) | ทุกคน |
| สแกนเอกสาร | สั่งเครื่องสแกนที่ต่อกับเซิร์ฟเวอร์ + รับไฟล์จากเครื่องอื่น | ผู้ดูแล, เจ้าหน้าที่ |
| อัปโหลดเอกสาร | เพิ่มเอกสารจากไฟล์ที่มีอยู่แล้ว | ผู้ดูแล, เจ้าหน้าที่ |
| สแกนทีละปึก (ใบปะหน้า) | พิมพ์ใบปะหน้า และสแกนทั้งปึกให้ระบบแยกเอง | ผู้ดูแล, เจ้าหน้าที่ |
| สถานีสแกน | โหมดทำงานสแกนต่อเนื่อง ยิงบาร์โค้ดทีละฉบับ | ผู้ดูแล, เจ้าหน้าที่ |
| ยืม-คืนตัวจริง | ทะเบียนว่าใครยืมต้นฉบับกระดาษอยู่ | ทุกคน |
| รายงาน | รายงานผู้บริหาร 4 แบบ | ผู้ดูแล |
| ทำลายเอกสาร | ทำบัญชีหนังสือขอทำลายตามระเบียบ | ผู้ดูแล |
| ความปลอดภัยบัญชี | 2FA, อุปกรณ์ที่ล็อกอิน, Token เครื่องสแกน | ทุกคน (Token เฉพาะผู้ดูแล/เจ้าหน้าที่) |
| ตั้งค่าระบบและผู้ใช้ | ตั้งค่าทุกอย่าง (มีหลายแท็บ ดูหัวข้อ 5.23) | ผู้ดูแล |
| 🔔 กระดิ่ง (มุมขวาบน) | แจ้งเตือนสิ่งที่ต้องทำ | ทุกคน |
| 🔑 (มุมขวาบน) | เปลี่ยนรหัสผ่านของตัวเอง | ทุกคน |

## 4. เริ่มต้นใช้งานครั้งแรก

**ผู้ดูแลระบบทำตามลำดับนี้ (ประมาณ 15 นาที):**

1. เปิด `http://<ที่อยู่เซิร์ฟเวอร์>/setup.php` ตั้งชื่อผู้ใช้และรหัสผ่านของผู้ดูแลระบบคนแรก (หน้านี้ใช้ได้ครั้งเดียว ตอนยังไม่มีผู้ใช้เลย)
2. ล็อกอิน แล้วไปที่ **ตั้งค่า › แฟ้มจัดเก็บ** สร้างแฟ้มที่จะใช้ (เช่น "ฎีกา 2569")
3. **ตั้งค่า › รหัสและอายุการเก็บ** สร้างคำนำหน้ารหัส (เช่น `DOC` = ทั่วไป, `INV` = ใบเสร็จ) และกำหนดจำนวนปีที่ต้องเก็บของแต่ละประเภท
4. **ตั้งค่า › ดัชนีเพิ่มเติม** เพิ่มช่องข้อมูลที่ต้องการค้นหา เช่น "จำนวนเงิน" (ตัวเลข) "หน่วยงาน" (ข้อความ) — ชื่อ "จำนวนเงิน" และ "หน่วยงาน" ใช้กับการค้นหาขั้นสูงและรายงาน (เปลี่ยนชื่อช่องที่ใช้ได้ที่ นโยบาย PDPA และความปลอดภัย)
5. **ตั้งค่า › ผู้ใช้และสิทธิ์** สร้างบัญชีให้เจ้าหน้าที่/ผู้ดูเอกสาร กำหนดแฟ้มที่แต่ละคนเข้าถึงได้
6. **ตั้งค่า › ค่าระบบ** ใส่ "ที่อยู่เว็บ (URL สาธารณะ)" ให้ถูก เพราะจะถูกฝังใน QR Code ที่ประทับบนเอกสาร (ถ้าผิด QR จะเปิดไม่ถูกหน้า)
7. **ตั้งค่า › พื้นที่และสำรองข้อมูล** กดสำรองข้อมูลครั้งแรก แล้วใส่ที่เก็บสำรองภายนอก (NAS/ไดรฟ์ภายนอก) ถ้ามี
8. เปิด 2FA ให้บัญชีผู้ดูแลที่ **ความปลอดภัยบัญชี** (แนะนำมาก)

## 5. คู่มือทีละฟีเจอร์

> รูปแบบ: **คืออะไร** → **ใช้ตอนไหน** → **วิธีใช้** → **ข้อควรรู้**

### 5.1 คลังเอกสาร — ค้นหาและเปิดดู
- **คืออะไร:** หน้ารวมเอกสารทั้งหมด เป็นตาราง แต่ละแถวคือ 1 เอกสาร (รหัส ชื่อเรื่อง แฟ้ม วันที่ วันครบอายุ สถานะ ป้ายต่าง ๆ)
- **ค้นหา:** พิมพ์ในช่อง "ค่าค้นหา" ได้ทั้ง รหัส ชื่อเรื่อง แท็ก ค่าในดัชนีเพิ่มเติม และ **ข้อความที่อยู่ในไฟล์ PDF** (ถ้าไฟล์อ่านข้อความได้) ค้นได้ทุกเอกสาร ไม่จำกัดจำนวน แบ่งหน้าให้อัตโนมัติ
- **ตัวกรองด่วน (ปุ่มกลม ๆ ด้านบน):** ทั้งหมด · ใกล้ครบอายุ · ครบอายุแล้ว · รอตรวจสอบ · ฉบับร่าง · ขอทำลาย · ยังไม่มีไฟล์ · ถังขยะ (เฉพาะผู้ดูแล)
- **ตัวกรองอื่น:** แฟ้ม · ช่วงวันที่ (นับจากวันที่จ่ายเงิน หรือวันที่นำเข้า) · เรียงตาม (ล่าสุด, รหัส, วันที่, ใกล้ครบอายุ) · ปุ่มล้างตัวกรอง
- **ค้นหาขั้นสูง** (ปุ่ม "ค้นหาขั้นสูง"): กรองเพิ่มได้ด้วย ปีงบประมาณไทย (เริ่ม 1 ต.ค. – สิ้นสุด 30 ก.ย. นับจากวันที่จ่ายเงิน หรือจากช่องดัชนีชื่อ "ปีงบประมาณ" ถ้ามี) · ช่วงจำนวนเงิน · หน่วยงาน · ช่องดัชนีใดก็ได้ + ค่า · ที่เก็บตัวจริง (หรือ "ยังไม่ระบุ") · สถานะยืม (กำลังยืม / เกินกำหนด) · มี/ไม่มีข้อมูลส่วนบุคคล
- **บันทึกการค้นหา:** ตั้งเงื่อนไขไว้แล้วกดปุ่มบุ๊กมาร์ก ตั้งชื่อ ครั้งหน้าเลือกจากรายการ "การค้นหาที่บันทึกไว้" ได้เลย (เก็บแยกรายคน)
- **ส่งออก CSV:** ปุ่ม "ส่งออก CSV" ได้ตารางตามตัวกรองปัจจุบัน เปิดใน Excel ได้ภาษาไทยไม่เพี้ยน (ผู้ที่ไม่มีสิทธิ์เห็นข้อมูลส่วนบุคคลจะได้ตัวเลขที่ถูกปิดบังไว้)
- **ป้ายบนแถว:** ปกติ/ครบอายุ · ขั้นตอน (ฉบับร่าง/รอตรวจสอบ/อนุมัติ) · PDPA (มีข้อมูลส่วนบุคคล) · ถูกยืม · ที่เก็บตัวจริง
- **ข้อควรรู้:** เห็นเฉพาะแฟ้มที่ผู้ดูแลให้สิทธิ์ ปุ่ม "เปิดดูไฟล์" ใช้ดูในหน้าต่างตัวอย่าง

### 5.2 หน้ารายละเอียดเอกสาร
กดที่แถวเอกสาร จะเปิดหน้าต่างรายละเอียด ด้านบนเป็นปุ่มคำสั่ง ด้านล่างเป็นแท็บ

**แท็บ:** ข้อมูลเอกสาร · ไฟล์ · ตัวจริง/ยืม-คืน · เอกสารที่เกี่ยวข้อง · เวอร์ชันเก่า · ประวัติ

**ปุ่มคำสั่ง (ขึ้นเฉพาะที่เกี่ยวข้อง/มีสิทธิ์):**
| ปุ่ม | ทำอะไร |
|---|---|
| เปิดดูไฟล์ | ดูไฟล์ PDF/รูปภาพในหน้าต่างตัวอย่าง |
| แก้ไข | แก้ชื่อเรื่อง แฟ้ม วันที่ ดัชนี แท็ก เพิ่ม/นำออกไฟล์ (ระบบกันการแก้ซ้อนกัน ถ้ามีคนแก้ไปก่อนจะเตือน) |
| บาร์โค้ด | พิมพ์ป้ายบาร์โค้ดของรหัสเอกสาร ไว้ติดแฟ้มกระดาษ |
| ใบปะหน้าสแกน | พิมพ์ใบปะหน้าของเอกสารนี้ (ดู 5.5) |
| ลิงก์ผู้ตรวจ | สร้างลิงก์ให้คนนอกเปิดดู (ดู 5.15) — ผู้ดูแล |
| ระบุว่ามีข้อมูลส่วนบุคคล / ยกเลิกระบุ | ติด/เอาป้าย PDPA ด้วยมือ — ผู้ดูแล |
| หน้าตรวจสอบ QR | เปิดหน้าสาธารณะที่คนนอกจะเห็นเมื่อสแกน QR |
| ส่งตรวจ / อนุมัติ / ตีกลับเป็นร่าง | เปลี่ยนสถานะ (ดู 5.10) |
| ขอทำลาย | ขอทำลายเอกสารที่ครบอายุ (ดู 5.16) |
| ย้ายไปถังขยะ / กู้คืน / ลบถาวร | ผู้ดูแลเท่านั้น |

- **แท็บไฟล์:** รายการไฟล์ของเอกสาร ปุ่มดูตัวอย่าง ดาวน์โหลด (ถ้ามีสิทธิ์) ดาวน์โหลด "ต้นฉบับก่อนประทับ QR" **แก้ไขหน้า** (ดู 5.9) และนำไฟล์ออก (ไฟล์ที่นำออกยังเก็บอยู่ในแท็บ "เวอร์ชันเก่า" ไม่หาย)
- **แท็บเวอร์ชันเก่า:** ทุกครั้งที่แทนที่ไฟล์หรือแก้หน้า ฉบับก่อนหน้าจะถูกเก็บไว้ที่นี่ย้อนดูได้
- **แท็บประวัติ:** ใครทำอะไรกับเอกสารนี้เมื่อไร (สร้าง แก้ไข เปิดดู ดาวน์โหลด ยืม ฯลฯ)

### 5.3 อัปโหลดเอกสาร (เพิ่มเอกสารจากไฟล์ที่มีอยู่)
- **ใช้ตอนไหน:** มีไฟล์ PDF/รูปภาพอยู่แล้ว (สแกนมาจากโปรแกรมอื่น หรือส่งทางอีเมล)
- **วิธีใช้:**
  1. ฝั่งซ้าย "ข้อมูลเอกสารและดัชนี": เลือกคำนำหน้า ระบบเสนอรหัสถัดไปให้ (ถ้ารหัสถูกใช้ตัดหน้าไป ระบบจะออกเลขใหม่ให้เองตอนบันทึก) ใส่ชื่อเรื่อง เลือกแฟ้ม วันที่จ่ายเงิน (ระบบคำนวณวันครบอายุให้) ดัชนี และแท็ก
  2. ฝั่งขวา "เลือกไฟล์เอกสาร": ลากไฟล์มาวาง หรือกดเลือก (PDF, JPG, PNG, TIFF เลือกได้หลายไฟล์ ขนาดสูงสุดต่อไฟล์แสดงในหน้า)
  3. กด **บันทึกและจัดเก็บเอกสาร**
- **ระบบทำอะไรให้อัตโนมัติ:**
  - รูปภาพ/TIFF → แปลงเป็น PDF ให้
  - **ตรวจคุณภาพ:** เตือนถ้าภาพ **มืด / เบลอ / เอียง** หรือ **จำนวนหน้าไม่ตรงที่ควรได้** (ถ้ากรอกช่อง "จำนวนหน้าที่ควรได้") — เป็นแค่คำเตือน ไม่ห้ามบันทึก
  - **เตือนไฟล์ซ้ำ:** ถ้าไฟล์นี้เคยอยู่ในระบบแล้ว (เทียบด้วย SHA-256) จะบอกว่าซ้ำกับเอกสารไหน (เฉพาะที่คุณมีสิทธิ์เห็น)
  - **ประทับ QR Code** ที่มุมขวาล่างทุกหน้า และเก็บ "ต้นฉบับก่อนประทับ" แยกไว้
  - อ่านข้อความในไฟล์เพื่อให้ค้นหาได้ (ทำเบื้องหลัง อาจใช้เวลาครู่หนึ่ง)
  - ตรวจว่ามีข้อมูลส่วนบุคคลหรือไม่ ติดป้าย PDPA ให้
- **ปุ่มต่อไฟล์แต่ละรายการ:** เลื่อนลำดับ · ดูตัวอย่าง · **จัดหน้า** (หมุน ลบ จัดเรียง แทรกหน้า) · **บีบอัด** (ทำให้ไฟล์เล็กลงโดยแปลงเป็นภาพเทา JPEG เหมาะกับเอกสารตัวหนังสือ) · นำออก
- **รวมหลายไฟล์:** ปุ่ม "รวมทุกไฟล์เป็น PDF เดียวและจัดหน้า" หรือติ๊ก "บันทึกแต่ละไฟล์เป็นเอกสารแยกกัน" (ระบบจะสร้างเอกสารหลายฉบับ ใส่ลำดับ (1/3) (2/3) ต่อท้ายชื่อ)
- **บันทึกเป็นฉบับร่าง:** ติ๊กไว้ถ้ายังไม่พร้อมให้ตรวจ ระบบเก็บเป็น "ฉบับร่าง" ก่อน
- **ข้อควรรู้:** ถ้าเป็นผู้ดูแลบันทึก เอกสารเป็น "อนุมัติแล้ว" ทันที ถ้าเป็นเจ้าหน้าที่จะเป็น "รอตรวจสอบ"

### 5.4 สแกนเอกสาร (สั่งเครื่องสแกนที่ต่อกับเซิร์ฟเวอร์)
- **คืออะไร:** กดปุ่มในเว็บ ให้เครื่องสแกน (ออกแบบไว้สำหรับ Canon DR-G2110 ผ่านโปรแกรม NAPS2) ดึงกระดาษแล้วได้ไฟล์เข้าระบบ
- **วิธีใช้:** เลือกค่าการสแกน (หรือกดโปรไฟล์สำเร็จรูป ดู 5.7) → ใส่ข้อมูลเอกสารเหมือนหน้าอัปโหลด → กดเริ่มสแกน งานจะเข้า **คิว** ทำเบื้องหลัง (หน้าเว็บไม่ค้าง มีงานเดียวสแกนพร้อมกันได้ งานอื่นรอคิว กดยกเลิกงานที่รอคิวได้)
- **ตัวเลือก:**
  - ความละเอียด 150–600 DPI (300 แนะนำ)
  - โหมดสี: สี / ขาวดำ(เทา) / ขาวดำชัด (ไฟล์เล็กสุด)
  - แหล่งกระดาษ: ถาดป้อนหน้าเดียว / ถาดป้อน 2 หน้า / กระจก
  - รูปแบบไฟล์ PDF/PNG/JPEG/TIFF และขนาดกระดาษ A4/A3/Letter/Legal
  - **คุณภาพ JPEG** (60% ไฟล์เล็กลง · 45% เล็กมากเหมาะกับตัวหนังสือ · 90% คมแต่ไฟล์ใหญ่)
  - ปรับภาพเอียงอัตโนมัติ · ข้ามหน้าว่าง · OCR ไทย/อังกฤษ (ให้ PDF ค้นหาข้อความได้ ต้องลงชุดภาษาไทยใน NAPS2) · แยกเอกสารด้วยแผ่นคั่น Patch-T · บันทึกเป็น PDF/A-2b (มาตรฐานเก็บระยะยาว)
- **กล่อง "ไฟล์จากเครื่องสแกนอื่นรอจัดเก็บ":** ถ้ามีเครื่องอื่นส่งไฟล์มา (ดู 5.8) จะขึ้นที่นี่ กด "ใช้ไฟล์นี้" เพื่อนำเข้ามาทำเอกสาร
- **ข้อควรรู้:** ต้องติดตั้ง NAPS2 บนเครื่องเซิร์ฟเวอร์และตั้งค่าที่ `config/scanner.php` (ดูหัวข้อ 8) ส่วนใหญ่ถ้าไม่มีเครื่องสแกนต่อกับเซิร์ฟเวอร์ ให้ใช้ข้อ 5.5–5.8 แทน

### 5.5 สแกนทีละปึกด้วยใบปะหน้า
- **คืออะไร:** วิธีสแกนเอกสารหลายฉบับ **ครั้งเดียวทั้งปึก** แล้วให้ระบบแยกเป็นเอกสารแต่ละฉบับเอง โดยใช้ "ใบปะหน้า" เป็นตัวคั่น
- **ใช้ตอนไหน:** มีเอกสารเป็นกอง ๆ (เช่น ฎีกา 50 ชุด) ไม่อยากสแกนและกรอกข้อมูลทีละฉบับ
- **วิธีใช้ (3 ขั้น):**
  1. **เตรียมใบปะหน้า** (ฝั่งซ้าย): เลือกคำนำหน้า แฟ้ม วันที่จ่ายเงิน ที่เก็บตัวจริง แท็ก จำนวนหน้าที่ควรได้ (ถ้าเท่ากันทุกชุด) แล้ว **พิมพ์ชื่อเรื่องบรรทัดละ 1 เอกสาร** (หรือใส่ชื่อเดียวแล้วระบุจำนวนใบ) กด "สร้างเอกสารและพิมพ์ใบปะหน้า" → ระบบสร้างเอกสารเปล่า ๆ ตามรหัสและเปิดหน้าพิมพ์ A4 (QR + บาร์โค้ด + ข้อมูล) ถ้ามีเอกสารอยู่แล้ว พิมพ์ใบปะหน้าซ้ำได้โดยใส่รหัสในช่อง "พิมพ์ใบปะหน้าให้เอกสารที่มีอยู่แล้ว"
  2. **วางใบปะหน้า** ไว้ **หน้าแรกของเอกสารแต่ละชุด** แล้วใส่ทั้งปึกเข้าเครื่องสแกน
  3. **สแกนทั้งปึก** (หรือกด "เลือกไฟล์ PDF/TIFF ทั้งปึก" ถ้าสแกนไว้แล้ว) ระบบอ่าน QR บนใบปะหน้า แล้วแสดง **ตารางผลการแยก**: ใบปะหน้าอยู่หน้าที่เท่าไร → เอกสารรหัสอะไร → กี่หน้า (หน้าที่ x–y) → ตรวจสอบ (เช่น "ควรได้ 2 หน้า", "มีไฟล์อยู่แล้ว จะต่อท้าย", "ไม่พบรหัสนี้/ไม่มีสิทธิ์") ตรวจดูแล้วกด **บันทึกเข้าเอกสาร**
- **ข้อควรรู้:** อ่าน QR ในเบราว์เซอร์ของคุณ ไม่ใช่บนเซิร์ฟเวอร์ (ต้องสแกนให้ QR ชัด) ถ้ามีหน้าที่อยู่ก่อนใบปะหน้าใบแรก ระบบจะเตือนว่า "N หน้าแรกไม่มีใบปะหน้า" และไม่นำหน้าเหล่านั้นไปแนบเอกสารใด

### 5.6 สถานีสแกน
- **คืออะไร:** หน้าจอสำหรับคนที่สแกนต่อเนื่องทั้งวัน ใช้ได้ทั้งเครื่องยิงบาร์โค้ดหรือคีย์บอร์ด
- **วิธีใช้:** เลือกโปรไฟล์ → ยิงบาร์โค้ดบนใบปะหน้า/ป้ายแฟ้ม (หรือพิมพ์รหัสแล้ว Enter) → ระบบแสดงชื่อเอกสาร → วางกระดาษแล้วกด **Enter หรือ F2** เพื่อสแกน (หรือกด "เลือกไฟล์" ถ้าสแกนมาจากที่อื่น) → ระบบแนบเข้าเอกสารนั้นเลย กด **Esc** เพื่อเริ่มฉบับใหม่
- ด้านขวามี "สแกนแล้วในรอบนี้" บอกว่าทำไปกี่ฉบับ และมีเสียงบอกสำเร็จ/ผิดพลาด

### 5.7 โปรไฟล์สแกน
- **คืออะไร:** ชุดค่าการสแกนที่ตั้งชื่อไว้ เช่น "ฎีกา = ขาวดำ 300 DPI สองหน้า" กดครั้งเดียวได้ค่าครบ
- **ตั้งค่า:** ผู้ดูแลที่ **ตั้งค่า › โปรไฟล์สแกน › เพิ่มโปรไฟล์** กำหนด ชื่อ ความละเอียด สี แหล่งกระดาษ คุณภาพ JPEG ตัวเลือก (ปรับเอียง/ข้ามหน้าว่าง/OCR/PDF-A) และตั้งล่วงหน้าได้ว่าใช้คำนำหน้าไหน แฟ้มไหน จำนวนหน้าที่ควรได้เท่าไร
- **ใช้:** ปุ่มโปรไฟล์ปรากฏในหน้าสแกน สแกนทีละปึก และสถานีสแกน

### 5.8 สแกนจากเครื่องอื่นในสำนักงาน (โปรแกรม Agent)
- **คืออะไร:** โปรแกรมเล็ก (ไฟล์ `tools/agent/edms-agent.ps1`) ติดตั้งบนคอมที่ต่อเครื่องสแกน แล้วส่งไฟล์เข้าระบบกลาง ไม่ต้องล็อกอินเว็บบนเครื่องนั้น
- **วิธีตั้ง:** ที่ **ความปลอดภัยบัญชี › Token เครื่องสแกนอื่น** กด "สร้าง token" ตั้งชื่อเครื่อง **คัดลอก token เก็บไว้ทันที (แสดงครั้งเดียว)** แล้วบนเครื่องปลายทางรัน (PowerShell):
  - ตรวจการเชื่อมต่อ: `.\edms-agent.ps1 -Server http://<เซิร์ฟเวอร์>/Website-SDU -Token <token> -Mode ping`
  - สแกนแล้วส่ง: `... -Mode scan -Source duplex -Color bw -Target DOC000123` (`-Target` คือรหัสเอกสารปลายทาง ไม่ใส่ก็ได้)
  - ส่งไฟล์ที่มีอยู่: `... -Mode send -File C:\Scans\a.pdf`
  - เฝ้าโฟลเดอร์ส่งอัตโนมัติ (เช่น เครื่องสแกนมีปุ่มบันทึกลงโฟลเดอร์): `... -Mode watch -WatchFolder C:\Scans`
- **ไฟล์ไปอยู่ไหน:** เข้า "กล่องรับไฟล์" ของเจ้าของ token (หน้า สแกนเอกสาร) กด "ใช้ไฟล์นี้" หรือ "ทิ้ง" ได้ · ระบบเก็บ token เป็นค่าแฮช (ดูค่าจริงย้อนหลังไม่ได้) ยกเลิก token ได้ทันทีที่หน้าเดิม

### 5.9 แก้ไขหน้าในเอกสาร (แทรก/แทนที่/หมุน/ลบหน้า)
- **ใช้ตอนไหน:** สแกนขาดหน้า สแกนมาหน้าเบลอ ต้องแทนที่ด้วยหน้าใหม่ หน้ากลับหัว หรือมีหน้าเกิน
- **วิธีใช้:** ที่แท็บ **ไฟล์** ของเอกสาร กดปุ่มไม้กายสิทธิ์ (แก้ไขหน้า) → เห็นรูปย่อทุกหน้า: หมุนซ้าย/ขวา เลื่อน ลบ **แทนที่** (เลือกไฟล์ใหม่มาแทนหน้านั้น) หรือกด **แทรกหน้าจากไฟล์** (แทรกหลังหน้าที่เลือกอยู่) → กด **บันทึกเป็น PDF**
- **ผลลัพธ์:** ระบบสร้างไฟล์เวอร์ชันใหม่ ประทับ QR ใหม่ ส่วน **ไฟล์เดิมเก็บในแท็บ "เวอร์ชันเก่า"** ไม่หาย ถ้าเจ้าหน้าที่แก้เอกสารที่ "อนุมัติแล้ว" เอกสารจะถูกส่งกลับไป "รอตรวจสอบ" อัตโนมัติ (ผู้ดูแลแก้แล้วสถานะคงเดิม)

### 5.10 ขั้นตอนงาน: ฉบับร่าง → รอตรวจสอบ → อนุมัติ
- **ฉบับร่าง:** ยังไม่เสร็จ ทำคนเดียว
- **รอตรวจสอบ:** เจ้าหน้าที่กด "ส่งตรวจ" ให้ผู้ดูแลดู (ขึ้นในกระดิ่งของผู้ดูแล)
- **อนุมัติแล้ว:** ผู้ดูแลกด "อนุมัติ" หรือ "ตีกลับเป็นร่าง" (ใส่เหตุผลได้)
- **กฎสำคัญ:** เจ้าหน้าที่ **อนุมัติเองไม่ได้** · ถ้าเจ้าหน้าที่แก้เอกสารที่อนุมัติแล้ว เอกสารจะกลับไปรอตรวจใหม่ (กันแก้แล้วไม่มีคนตรวจ) · ผู้ดูแลอนุมัติ/ตีกลับ/ย้ายลงถังขยะทีละหลายฉบับได้ (5.14)

### 5.11 QR Code และหน้าตรวจสอบเอกสาร
- **คืออะไร:** ทุกหน้า PDF ที่เก็บในระบบมี QR ที่มุมขวาล่าง ใครก็ตามที่ถือเอกสารสแกนด้วยมือถือจะเห็นหน้า "ตรวจสอบเอกสาร" (ไม่ต้องล็อกอิน) บอกรหัส ชื่อเรื่อง ว่ามีอยู่จริงในระบบ
- **ตรวจว่าไฟล์ถูกแก้ไหม:** ในหน้านั้นอัปโหลดไฟล์ที่ถืออยู่ เพื่อเทียบ SHA-256 กับต้นฉบับในระบบ ถ้าไม่ตรง แปลว่าไฟล์ถูกแก้ไขหลังจากเก็บ
- **ความปลอดภัย:** QR ใช้รหัสสุ่มยาวเดาไม่ได้ (QR รุ่นเก่าแบบเลขเอกสารยังใช้ได้แต่แสดงข้อมูลน้อยกว่า)
- **ข้อควรรู้:** ต้องตั้ง "ที่อยู่เว็บ (URL สาธารณะ)" ที่ ตั้งค่า › ค่าระบบ ให้ถูก เพื่อให้มือถือเปิดจากภายนอกได้

### 5.12 ที่เก็บต้นฉบับกระดาษ และทะเบียนยืม-คืน
- **คืออะไร:** ระบบจำว่ากระดาษต้นฉบับของแต่ละเอกสาร **วางไว้ที่ไหน** (ห้อง › ตู้ › ชั้น › กล่อง) และ **ใครยืมไปเมื่อไร ต้องคืนวันไหน**
- **ตั้งรายการที่เก็บ:** ผู้ดูแลที่ **ตั้งค่า › ที่เก็บตัวจริง › เพิ่มที่เก็บ** (ห้อง ตู้ ชั้น กล่อง หมายเหตุ) ตารางบอกด้วยว่าแต่ละที่มีเอกสารกี่ฉบับ
- **ระบุที่เก็บของเอกสาร:** เปิดเอกสาร แท็บ **ตัวจริง/ยืม-คืน** → เลือกที่เก็บ + หมายเหตุ (เช่น "ลำดับที่ 12 ในกล่อง") → บันทึกที่เก็บ (ทีละหลายฉบับก็ได้ ดู 5.14)
- **ยืม:** ที่แท็บเดียวกัน กรอก ชื่อผู้ยืม/หน่วยงาน วัตถุประสงค์ และวันกำหนดคืน (ย้อนหลังไม่ได้) → บันทึกการยืม เอกสารขึ้นป้าย "ถูกยืม" และ **ยืมซ้อนไม่ได้** จนกว่าจะคืน
- **คืน:** กด "บันทึกการคืน" (ใส่หมายเหตุได้)
- **ติดตามทั้งหมด:** เมนู **ยืม-คืนตัวจริง** แสดงรายการ กำลังยืม / เกินกำหนดคืน / ทั้งหมด เกินกำหนดจะแจ้งเตือนที่กระดิ่ง และค้นหา "เกินกำหนดคืน" ในค้นหาขั้นสูงได้

### 5.13 เอกสารที่เกี่ยวข้องกัน
- **คืออะไร:** เชื่อมโยงเอกสารที่เป็นชุดเดียวกัน เช่น ฎีกา ↔ ใบเสร็จ ↔ สัญญา
- **วิธีใช้:** แท็บ **เอกสารที่เกี่ยวข้อง** → ค้นหาเอกสารปลายทาง → เลือกประเภทความสัมพันธ์ (ฎีกา, ใบเสร็จรับเงิน, สัญญา, ใบส่งของ, ใบสั่งซื้อ, บันทึกขออนุมัติ, เอกสารแนบ, ฉบับแก้ไข, เกี่ยวข้อง) → เชื่อม ลิงก์เห็นได้จากทั้งสองฝั่ง กดไปเปิดเอกสารที่เกี่ยวข้องได้เลย (เชื่อมกับตัวเองไม่ได้)

### 5.14 จัดการทีละหลายฉบับ
- **วิธีใช้:** ที่คลังเอกสาร ติ๊กช่องหน้าแถว (หรือติ๊กหัวตารางเพื่อเลือกทั้งหน้า) จะมีแถบสีเข้มขึ้นด้านบน
- **คำสั่ง:** ย้ายแฟ้ม · เพิ่มแท็ก · ที่เก็บตัวจริง · ส่งตรวจ · อนุมัติ* · ใบปะหน้า (พิมพ์หลายใบ) · ลิงก์ผู้ตรวจ* · ถังขยะ* · กู้คืน* · ยกเลิกการเลือก (*เฉพาะผู้ดูแล)
- ระบบทำเท่าที่มีสิทธิ์ และบอกว่าทำกี่ฉบับ ข้ามกี่ฉบับ

### 5.15 ลิงก์สำหรับผู้ตรวจสอบภายนอก (เช่น สตง.)
- **คืออะไร:** ลิงก์พิเศษให้คนนอกเปิดดู **เฉพาะเอกสารที่เลือก** ได้ **โดยไม่ต้องมีบัญชี** และมีวันหมดอายุ
- **สร้าง:** ผู้ดูแลเลือกเอกสาร (จากหน้ารายละเอียด หรือเลือกหลายฉบับ) → "ลิงก์ผู้ตรวจ" → กรอก ผู้รับ, หมายเหตุ, ใช้ได้ถึงวันที่ (สูงสุด 180 วัน), ติ๊กว่าอนุญาตให้ดาวน์โหลดไหม → ได้ลิงก์ **แสดงครั้งเดียว** ให้คัดลอกส่ง
- **ผู้รับเห็นอะไร:** หน้าตารางเอกสารที่ถูกแชร์ + ปุ่มเปิดดูไฟล์ ทุกไฟล์มี **ลายน้ำ "REVIEW COPY"** และ **ระบบบันทึกทุกครั้งที่เปิด**
- **ควบคุม:** ตั้งค่า › ลิงก์ผู้ตรวจ ดูว่าใครได้ลิงก์ เปิดไปกี่ครั้ง ล่าสุดเมื่อไร และ **ยกเลิกได้ทันที** ลิงก์หมดอายุหรือถูกยกเลิกจะเปิดไม่ได้อีก
- **ระวัง:** เอกสารที่มีป้าย PDPA ก็แชร์ได้ถ้าผู้ดูแลเลือกเอง โปรดตรวจก่อนสร้างลิงก์ · เอกสารในถังขยะแชร์ไม่ได้

### 5.16 อายุการเก็บ ถังขยะ และการทำลายเอกสาร
**อายุการเก็บ:** วันที่จ่ายเงิน + จำนวนปีตามประเภท (ค่าเริ่มต้น 10 ปี) = วันครบอายุ ใกล้ครบอายุ (ค่าเริ่มต้น 90 วันก่อน) จะขึ้นเตือนที่กระดิ่งและตัวกรอง "ใกล้ครบอายุ"

**ถังขยะ:** ลบเอกสาร = ย้ายลงถังขยะ (กู้คืนได้ที่ตัวกรอง "ถังขยะ") แล้วถูกลบถาวรอัตโนมัติเมื่อครบจำนวนวันที่ตั้งไว้ (ค่าเริ่มต้น 30 วัน) **ลบถาวรแล้วกู้ไม่ได้**

**ทำลายเอกสาร 2 ทาง:**
1. **แบบรายฉบับ:** เจ้าหน้าที่เปิดเอกสารที่ **ครบอายุแล้ว** กด "ขอทำลาย" ใส่เหตุผล → ขึ้นตัวกรอง "ขอทำลาย" ผู้ดูแลกดอนุมัติ (เอกสารลงถังขยะ) หรือปฏิเสธ
2. **แบบตามระเบียบงานสารบรรณ (เมนู "ทำลายเอกสาร"):** ใช้เมื่อต้องทำ **บัญชีหนังสือขอทำลาย** เสนอคณะกรรมการ
   1. กด **สร้างบัญชีจากเอกสารครบอายุ** (หรือ "จากคำขอทำลาย") ระบบดึงรายการให้ — บอกจำนวนเอกสารครบอายุที่ยังไม่อยู่ในบัญชีไว้ด้านบน
   2. เปิดบัญชี **แต่งตั้งคณะกรรมการอย่างน้อย 3 คน** (ชื่อ ตำแหน่ง บทบาท: ประธานกรรมการ / กรรมการ / กรรมการและเลขานุการ)
   3. คณะกรรมการพิจารณารายฉบับ เลือก **"ทำลาย"** หรือ **"ขยายเวลาเก็บ"** (ระบุปี 1–50) พร้อมหมายเหตุ
   4. กด **ส่งคณะกรรมการพิจารณา** → **อนุมัติ** (ย้อนกลับไปแก้ร่างได้ก่อนอนุมัติ)
   5. กด **ดำเนินการ**: ที่ "ทำลาย" → ย้ายลงถังขยะ (แล้วถูกลบถาวรตามรอบ) · ที่ "ขยายเวลาเก็บ" → ต่อวันครบอายุและยกเลิกคำขอทำลาย
   6. **พิมพ์บัญชีหนังสือขอทำลาย** (หน้า A4 แนวนอน มีช่องลงชื่อกรรมการ) และ **พิมพ์รายงานประจำปี**
- **ข้อควรรู้:** ระบบ "ทำลาย" เฉพาะไฟล์ในระบบ **ไม่ได้ทำลายกระดาษต้นฉบับ** ต้องทำตามระเบียบนอกระบบ ทุกขั้นบันทึกในประวัติ บัญชีที่อนุมัติแล้วแก้ไม่ได้ ลบได้เฉพาะร่าง

### 5.17 รายงานผู้บริหารและแดชบอร์ด
- **แดชบอร์ดผู้บริหาร:** การ์ดสรุปจำนวนเอกสาร กราฟเอกสารเพิ่มรายสัปดาห์ สัดส่วนต่อแฟ้ม ผู้ใช้งานล่าสุด และประวัติการใช้งานระบบ
- **เมนูรายงาน** (4 แท็บ แต่ละแท็บส่งออก CSV ได้):
  1. **ตามปีงบประมาณและประเภท** — เอกสารกี่ฉบับ แยกตามปีงบประมาณ (ต.ค.–ก.ย.) และประเภท พร้อมจำนวนที่มีไฟล์แล้ว/ยังไม่มีไฟล์ (ใช้ไล่ว่าสแกนครบหรือยัง)
  2. **ผลงานสแกนรายบุคคล** — รายเดือน: ใครสร้างเอกสาร แนบไฟล์ กี่หน้า สั่งสแกนสำเร็จกี่งาน
  3. **พื้นที่ดิสก์และคาดการณ์** — เหลือที่ว่างเท่าไร ไฟล์เพิ่มวันละเท่าไร และคาดว่า **ดิสก์จะเต็มเมื่อไร** (ถ้าเกิน 10 ปีแสดงว่า "มากกว่า 10 ปี")
  4. **PDPA: ใครเข้าดูข้อมูลส่วนบุคคล** — รายชื่อผู้เปิดเอกสารที่มีข้อมูลส่วนบุคคล (เปิดไฟล์ ดาวน์โหลด เปิดรายละเอียด หรือผ่านลิงก์ผู้ตรวจ) เลือกช่วงวันที่ได้ ไว้ตอบคำถาม "ใครเข้าไปดูข้อมูลของใครบ้าง"

### 5.18 ข้อมูลส่วนบุคคล (PDPA)
- **คืออะไร:** ระบบ **หาเอง** ว่าเอกสารไหนมีเลขบัตรประชาชน 13 หลัก (ตรวจเลขท้ายว่าเป็นเลขจริง ไม่ใช่เลขมั่ว) หรือเลขบัญชีธนาคาร ทั้งในข้อความในไฟล์และในช่องดัชนี แล้วติดป้าย **PDPA**
- **ถ้าคุณ "ไม่มีสิทธิ์" ดูข้อมูลส่วนบุคคล จะเกิดอะไร:**
  - ตัวเลขถูกปิดบัง เช่น `3-1005-00123-45-6` → `X-XXXX-XXXXX-45-X` และเลขบัญชีเห็นแค่ 3 ตัวท้าย (ในรายการ ผลค้นหา ช่องดัชนี และไฟล์ CSV)
  - **เปิดไฟล์ของเอกสารนั้นไม่ได้เลย** (เพราะภาพสแกนปิดบังตัวเลขในภาพไม่ได้ จึงใช้วิธีไม่ให้เปิดแทน) ไฟล์ของเอกสารปกติเปิดได้ตามเดิม
- **ใครมีสิทธิ์:** ผู้ดูแลเสมอ + บทบาทที่ผู้ดูแลติ๊กไว้ที่ **ตั้งค่า › นโยบาย PDPA และความปลอดภัย › PDPA** (ค่าเริ่มต้น เฉพาะผู้ดูแล)
- **ติด/เอาป้ายเอง:** ผู้ดูแลกด "ระบุว่ามีข้อมูลส่วนบุคคล" หรือ "ยกเลิกระบุ" ที่หน้ารายละเอียด (ถ้ายกเลิกแต่ในไฟล์ยังมีเลขอยู่จริง ระบบจะตรวจเจอและติดป้ายกลับ)
- **ตามรอย:** ทุกครั้งที่ผู้มีสิทธิ์เปิดดู ถูกบันทึก (30 นาทีนับเป็น 1 ครั้งต่อเอกสาร) ดูได้ที่ รายงาน › PDPA

### 5.19 ลายน้ำและสิทธิ์ดาวน์โหลด
ตั้งที่ **ตั้งค่า › นโยบาย PDPA และความปลอดภัย**
- **สิทธิ์ดาวน์โหลด:** ติ๊กว่าบทบาทไหนดาวน์โหลดได้ (ผู้ดูแลได้เสมอ) บทบาทที่ไม่ติ๊ก **เปิดดูได้อย่างเดียว** ไม่มีปุ่มดาวน์โหลด
- **ลายน้ำ 3 โหมด:** ไม่ใส่ · ใส่เมื่อดาวน์โหลด · ใส่ทุกครั้งที่เปิดดู/พิมพ์/ดาวน์โหลด — ข้อความบอก ชื่อผู้ใช้ วันเวลา และ IP ของเครื่อง
- **ข้อควรรู้:** เจ้าหน้าที่ที่เปิดไฟล์เพื่อ "แก้ไขหน้า" จะได้ไฟล์ไม่มีลายน้ำ (ไม่งั้นลายน้ำจะติดเข้าไปในไฟล์ใหม่) · การพิมพ์ที่มีลายน้ำเฉพาะโหมด "ทุกครั้ง"

### 5.20 ลายมือชื่อดิจิทัลบน PDF
- **คืออะไร:** ฝังลายเซ็นอิเล็กทรอนิกส์ไว้ในทุก PDF ที่เก็บใหม่ เปิดใน Adobe Reader จะเห็นแถบลายมือชื่อ ถ้ามีใครแก้ไฟล์ภายหลังจะขึ้นเตือน ไฟล์ที่ดาวน์โหลด (มีลายน้ำ) ก็ถูกเซ็นซ้ำให้ด้วย
- **เปิดใช้:** นโยบาย PDPA และความปลอดภัย › ลายมือชื่อดิจิทัลบน PDF → ติ๊กเปิด + ใส่ชื่อหน่วยงาน (อังกฤษ ใช้ในใบรับรอง) ระบบสร้างใบรับรองให้เอง
- **ข้อควรรู้:** ใบรับรองที่ระบบสร้างเอง **Adobe ยังไม่ไว้ใจ** (ขึ้นเตือน "ไม่ทราบผู้ออก") ใช้งานจริงควรกด **ติดตั้งใบรับรอง** อัปโหลดไฟล์ `.p12` / `.pfx` ที่หน่วยงานขอจากผู้ออกใบรับรอง และยังไม่มีตราเวลาจากหน่วยงานภายนอก

### 5.21 ความปลอดภัยบัญชี: 2FA และอุปกรณ์ที่ล็อกอิน
เมนู **ความปลอดภัยบัญชี**
- **เปิด 2FA:** กด "เปิดการยืนยันตัวตนสองขั้น" → ติดตั้งแอป Google/Microsoft Authenticator ในมือถือ → สแกน QR ที่ขึ้น (หรือพิมพ์รหัสที่ให้) → กรอกรหัส 6 หลักยืนยัน → ได้ **รหัสกู้คืน 10 ชุด จดเก็บไว้** (แสดงครั้งเดียว) ครั้งต่อไปล็อกอินต้องกรอกรหัสจากแอปด้วย (กรอกผิดเกิน 5 ครั้งต้องล็อกอินใหม่)
- **สร้างรหัสกู้คืนชุดใหม่ / ปิด 2FA:** ต้องยืนยันด้วยรหัสผ่านก่อน
- **บังคับผู้ดูแลทุกคนใช้ 2FA:** ตั้งที่นโยบายความปลอดภัย (ผู้ที่ยังไม่เปิดจะถูกแจ้งเตือนที่กระดิ่งจนกว่าจะเปิด)
- **ทำมือถือหาย:** ใช้รหัสกู้คืนแทนรหัส 6 หลัก หรือให้ผู้ดูแลกด **รีเซ็ต 2FA** ที่ ตั้งค่า › ผู้ใช้และสิทธิ์ (ถ้าผู้ดูแลคนเดียวหมด ให้ใช้คำสั่งในหัวข้อ 6)
- **อุปกรณ์ที่เข้าสู่ระบบอยู่:** ตารางแสดง อุปกรณ์/เบราว์เซอร์ IP เวลาเข้าและใช้ล่าสุด กด **ออกจากระบบ** รายเครื่อง หรือ **ออกจากระบบอุปกรณ์อื่นทั้งหมด** (เครื่องที่ใช้อยู่ยังอยู่) ผู้ดูแลติ๊ก "แสดงของทุกคน" ได้ — เหมาะกับกรณีลืมล็อกเอาต์เครื่องสาธารณะ หรือสงสัยว่ามีคนแอบใช้บัญชี
- **ล็อกอินผิด 5 ครั้ง** บัญชีถูกล็อก 15 นาที (ผู้ดูแลกด "ปลดล็อก" ได้ที่หน้าผู้ใช้)

### 5.22 กระดิ่งแจ้งเตือนในระบบ
กดรูประฆังมุมขวาบน จะเห็นสิ่งที่ต้องทำ (ตัวเลขแดงคือจำนวนรายการ) กดที่แถวเพื่อไปหน้านั้นพร้อมตัวกรองให้ — ตัวอย่างรายการ:

| แจ้งเตือน | ใครเห็น |
|---|---|
| เอกสารรออนุมัติ · มีคำขอทำลาย | ผู้ดูแล |
| ไฟล์เสียหายหรือถูกแก้ไข (ผลตรวจล่าสุด) | ผู้ดูแล |
| ยังไม่เคยสำรองข้อมูล / ไม่ได้สำรองเกิน 7 วัน | ผู้ดูแล |
| ควร/ต้องเปิดการยืนยันตัวตนสองขั้น | ตามบัญชี |
| ฉบับร่างของฉันที่ยังไม่ส่งตรวจ · ไฟล์จากเครื่องสแกนอื่นรอจัดเก็บ · เอกสารที่พิมพ์ใบปะหน้าแล้วแต่ยังไม่มีไฟล์ | ผู้ดูแล/เจ้าหน้าที่ |
| เอกสารใกล้ครบอายุ · ยืมตัวจริงเกินกำหนดคืน | ทุกคนที่มีสิทธิ์เห็นเอกสารนั้น |

### 5.23 ตั้งค่าระบบและผู้ใช้ (ผู้ดูแลเท่านั้น) — ทุกแท็บ
| แท็บ | ไว้ทำอะไร |
|---|---|
| แฟ้มจัดเก็บ | สร้าง/แก้ไข/ลบแฟ้ม (เลือกหลายแฟ้มลบพร้อมกันได้) |
| รหัสและอายุการเก็บ | คำนำหน้ารหัสเอกสาร และจำนวนปีที่ต้องเก็บของแต่ละประเภท |
| ดัชนีเพิ่มเติม | ช่องข้อมูลเพิ่มเอง (ข้อความ/ตัวเลข/วันที่ จะบังคับกรอกหรือไม่ก็ได้) |
| ผู้ใช้และสิทธิ์ | เพิ่มผู้ใช้ กำหนดบทบาท แฟ้มที่เข้าถึงได้ รีเซ็ตรหัสผ่าน ปลดล็อก รีเซ็ต 2FA ลบ (ลบตัวเอง/ผู้ดูแลคนสุดท้ายไม่ได้) |
| ค่าระบบ | ที่อยู่เว็บสาธารณะ (ใส่ใน QR) · อายุเก็บเริ่มต้น · เตือนก่อนครบอายุกี่วัน · เก็บถังขยะกี่วัน |
| พื้นที่และสำรองข้อมูล | ขนาดไฟล์/ดิสก์ · ไฟล์ขยะ · สั่งอ่านข้อความไฟล์ทั้งหมด · สำรองข้อมูล · **ตรวจความสมบูรณ์ของไฟล์** · **ทดลองกู้คืน** · ที่เก็บสำรองภายนอก (ดู 5.24) |
| ที่เก็บตัวจริง | รายการห้อง/ตู้/ชั้น/กล่อง (ดู 5.12) |
| โปรไฟล์สแกน | ชุดค่าการสแกน (ดู 5.7) |
| นโยบาย PDPA และความปลอดภัย | สิทธิ์ดาวน์โหลด · ลายน้ำ · ใครเห็นข้อมูลส่วนบุคคล · บังคับ 2FA ผู้ดูแล · ชื่อช่องจำนวนเงิน/หน่วยงานที่ใช้ค้นหาและรายงาน · ลายมือชื่อดิจิทัล |
| ลิงก์ผู้ตรวจ | รายการลิงก์ที่ออกไป ดูสถิติ ยกเลิกลิงก์ (ดู 5.15) |

### 5.24 สำรองข้อมูล ตรวจความสมบูรณ์ และทดลองกู้คืน
เพื่อให้มั่นใจว่า **เอกสารไม่หายและไม่ถูกแก้ไขเงียบ ๆ**
- **สำรองข้อมูล:** ฐานข้อมูล + ไฟล์ทั้งหมด เก็บไว้นอกโฟลเดอร์เว็บ (ดาวน์โหลดผ่านเว็บไม่ได้) เก็บ 14 ชุดล่าสุด ตั้งเวลาอัตโนมัติได้ (หัวข้อ 9) และ **คัดลอกซ้ำไปที่เก็บภายนอก** (NAS/ไดรฟ์ภายนอก) เมื่อใส่ path ไว้ — ระบบตรวจว่าที่คัดลอกไปไม่เสีย (เทียบ hash)
- **ตรวจความสมบูรณ์ของไฟล์:** ระบบคำนวณ SHA-256 ของทุกไฟล์ (ทั้งฉบับปัจจุบัน เวอร์ชันเก่า ฉบับประทับ QR ต้นฉบับ) เทียบกับค่าตอนเก็บ เจอไฟล์ **หาย เสีย หรือถูกแก้** จะรายงานและแจ้งเตือนผู้ดูแล กดตรวจเองหรือตั้งเวลาทุกเดือนได้
- **ปุ่มทดลองกู้คืน:** นำชุดสำรองล่าสุดไปลงในฐานข้อมูลชั่วคราว ตรวจว่าอ่านได้ ตัวเลขข้อมูลตรงกับปัจจุบัน และสุ่มตรวจ hash ของไฟล์ แล้วลบฐานข้อมูลชั่วคราวทิ้ง **ไม่กระทบข้อมูลจริง** — ควรกดเป็นระยะ เพราะ "สำรองแล้ว" ไม่ได้แปลว่า "กู้คืนได้จริง"

## 6. สถานการณ์ที่เจอบ่อย (ถาม-ตอบ)

**ลืมรหัสผ่าน / บัญชีผู้ดูแลหมด?**
ผู้ดูแลคนอื่นรีเซ็ตให้ได้ที่ ตั้งค่า › ผู้ใช้และสิทธิ์ ถ้าไม่มีผู้ดูแลเหลือ ให้คนดูแลเครื่องเซิร์ฟเวอร์รันคำสั่ง (ตั้งรหัสใหม่ + ปิด 2FA + ออกจากระบบทุกเครื่อง):
```
php tools/reset_password.php <ชื่อผู้ใช้>
```

**ขึ้นว่าบัญชีถูกล็อก?** กรอกรหัสผิดครบ 5 ครั้ง รอ 15 นาที หรือให้ผู้ดูแลกด "ปลดล็อก"

**เปิดไฟล์ไม่ได้ ขึ้น "เอกสารนี้มีข้อมูลส่วนบุคคล"?** บัญชีคุณยังไม่มีสิทธิ์ดูข้อมูลส่วนบุคคล ขอผู้ดูแลเพิ่มสิทธิ์ที่นโยบาย PDPA

**ไม่มีปุ่มดาวน์โหลด / ขึ้น "ดาวน์โหลดไม่ได้"?** บทบาทของคุณไม่ได้อยู่ในสิทธิ์ดาวน์โหลด ดูได้อย่างเดียว

**ประทับ QR ไม่สำเร็จ ขึ้นเตือนว่าเก็บไฟล์ต้นฉบับแทน?** PDF บางชนิดที่บีบอัดแบบใหม่หรือมีรหัสผ่าน ระบบอ่านไม่ได้ ไฟล์ยังถูกเก็บไว้ใช้ได้ปกติ เพียงไม่มี QR/ลายน้ำ (เว็บพยายามแปลงไฟล์ให้ก่อนอัปโหลดอยู่แล้ว)

**สแกนทีละปึกแล้วจำนวนหน้าไม่ตรง?** ตารางผลจะเตือน "ควรได้ N หน้า" ให้ตรวจกระดาษว่าติดหรือขาดหน้า แล้วใช้ "แก้ไขหน้า" แทรกหน้าที่ขาด

**ลิงก์ผู้ตรวจเปิดไม่ได้?** อาจหมดอายุหรือถูกยกเลิก (ระบบแจ้ง "หมดอายุ/ถูกยกเลิก/ไม่พบลิงก์") ให้ผู้ดูแลออกลิงก์ใหม่

**ทำมือถือที่ใช้ 2FA หาย?** ใช้รหัสกู้คืน หรือให้ผู้ดูแลรีเซ็ต 2FA ให้

**ตัวเลขดิสก์เกือบเต็ม?** ดูรายงาน › พื้นที่ดิสก์ ลบไฟล์ขยะที่ ตั้งค่า › พื้นที่และสำรองข้อมูล ย้ายโฟลเดอร์สำรองไปไดรฟ์อื่น และพิจารณาบีบอัดไฟล์ตอนสแกน (JPEG 45–60%)

## 7. ข้อจำกัดที่ควรรู้

- **ยังไม่ได้ทดสอบกับเครื่องสแกน Canon จริง** (ต้องติดตั้ง NAPS2 บนเซิร์ฟเวอร์) ส่วนการแยกปึกด้วยใบปะหน้า สถานีสแกน และ Agent ทดสอบแล้วกับไฟล์จริง/จำลอง
- **ไม่มี JBIG2** (ทำบนเว็บไม่ได้) การ "บีบอัด" ใช้ภาพเทา JPEG แทน เหมาะกับเอกสารตัวหนังสือ
- **ลายมือชื่อดิจิทัล:** ใบรับรองที่ระบบสร้างเองยังไม่เป็นที่ยอมรับใน Adobe และยังไม่มีตราเวลาจากผู้ให้บริการภายนอก (TSA) — ใช้งานจริงควรติดตั้ง .p12 ของหน่วยงาน
- **ภาพสแกนปิดบังตัวเลข PDPA ไม่ได้** จึงใช้การบล็อกการเปิดไฟล์แทน
- **ต้องมีอินเทอร์เน็ตสำหรับหน้าเว็บ:** โหลดไลบรารี (pdf.js, pdf-lib, Chart.js, JsBarcode, jsQR) จาก CDN ถ้าเข้า CDN ไม่ได้ หน้าหลักจะโหลดไม่ขึ้น — ถ้าใช้ในเครือข่ายปิด ต้องดาวน์โหลดไลบรารีมาไว้ในเครื่อง
- **PDF บางไฟล์** (ใช้ compressed xref/object stream) ต้องผ่านการแปลงในเบราว์เซอร์ก่อนจึงประทับ QR/ลายน้ำได้ ไฟล์ที่ส่งตรงเข้า API โดยไม่ผ่านขั้นนี้ ระบบเก็บไว้ตามเดิมและแจ้งเตือน
- **การค้นหาข้อความ:** ผู้ที่ไม่มีสิทธิ์ PDPA ยังพิมพ์เลขบัตรเพื่อค้นหาเอกสารได้ (ระบบเห็นว่ามีเอกสารตรง แต่ปิดตัวเลขในผลลัพธ์)
- ใช้ **ไวยากรณ์ MariaDB** ตอนอัปเกรดฐานข้อมูลเดิม (XAMPP ใช้ได้) ระบบไม่เหมาะกับ Serverless อย่าง Vercel เพราะต้องเก็บไฟล์บนดิสก์และรันงานเบื้องหลังด้วย PHP

## 8. การติดตั้ง (สำหรับผู้ดูแลเครื่อง)

### 8.1 ติดตั้ง Dependencies
ต้องมี PHP 8.x (extensions: `pdo_mysql`, `mbstring`, `gd`, `fileinfo`, `openssl`) และ MariaDB/MySQL จากนั้นเปิด Terminal ในโฟลเดอร์โปรเจกต์:
```bash
composer install
```

### 8.2 สร้างฐานข้อมูล
สร้างฐานข้อมูลเปล่าชื่อ `dms_system` (หรือนำเข้า [database.sql](database.sql) ซึ่งสร้างให้) แล้วเปิดเว็บ ระบบจะสร้างตารางทั้งหมดจาก `config/schema.sql` และอัปเกรดเป็นเวอร์ชันล่าสุดให้เองเมื่อเรียกหน้าเว็บครั้งแรก
```bash
mysql -u root -p -e "CREATE DATABASE dms_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
```
> ฐานข้อมูลเดิมจากเวอร์ชันก่อนหน้าไม่ต้องทำอะไรเพิ่ม ระบบเพิ่มตาราง/คอลัมน์ใหม่ให้เอง (เพิ่มอย่างเดียว ไม่ลบ/เปลี่ยนชื่อของเดิม) — **แนะนำให้สำรองฐานข้อมูลก่อนอัปเกรดทุกครั้ง**

### 8.3 ตั้งค่าการเชื่อมต่อฐานข้อมูลและค่าเฉพาะเครื่อง
ค่าเริ่มต้น (`localhost`, `dms_system`, `root`, ไม่มีรหัสผ่าน) อยู่ใน [config/database.php](config/database.php) ถ้าต้องเปลี่ยน ให้คัดลอก [config/local.example.php](config/local.example.php) เป็น `config/local.php` แล้วแก้ `DB_HOST` / `DB_NAME` / `DB_USER` / `DB_PASS` และ path ต่าง ๆ เช่น `BACKUP_DIR`, `SIGN_KEY_DIR` (กุญแจลายมือชื่อ ต้องอยู่นอก htdocs) — ไฟล์ `local.php` **ไม่ขึ้น git** และเปิดผ่านเว็บไม่ได้

### 8.4 ตั้งค่าเครื่องสแกน (ถ้าสแกนจากเซิร์ฟเวอร์)
ตรวจสอบ [config/scanner.php](config/scanner.php):
- `NAPS2_CONSOLE_PATH` ชี้ไปที่ `NAPS2.Console.exe` ที่ติดตั้งจริง (เช่น `C:\Program Files\NAPS2\NAPS2.Console.exe`)
- `SCANNER_DEVICE_NAME` ตรงกับชื่อใน TWAIN Driver ของเครื่อง
- OCR ไทย: เปิด NAPS2 ดาวน์โหลดชุดภาษาไทยหนึ่งครั้ง
- เครื่องสแกนที่ไม่ได้ต่อกับเซิร์ฟเวอร์: ใช้ Agent (5.8)

### 8.5 สร้างบัญชีผู้ดูแลคนแรก
เปิด `http://localhost/Website-SDU/setup.php` ตั้งชื่อผู้ใช้/รหัสผ่านผู้ดูแล แล้วระบบพาไปหน้าหลัก (หน้านี้ใช้ได้เฉพาะตอนยังไม่มีผู้ใช้) จากนั้นทำตามหัวข้อ 4

## 9. การตั้งค่าเพิ่มเติมและงานอัตโนมัติ

- **`config/app.php`**: path ของ PHP CLI, mysqldump/mysql, โฟลเดอร์สำรองข้อมูล, โฟลเดอร์กุญแจลายมือชื่อ, Tesseract (ไม่บังคับ) · ปรับเฉพาะเครื่องได้ใน `config/local.php`
- **สำรองข้อมูลอัตโนมัติทุกวัน** (Command Prompt แบบ Administrator):
  ```
  schtasks /Create /SC DAILY /ST 02:00 /TN "EDMS Backup" /TR "C:\xampp\php\php.exe C:\xampp\htdocs\Website-SDU\tools\backup.php"
  ```
- **ตรวจความสมบูรณ์ของไฟล์ทุกเดือน** (แก้ path ให้ตรงกับเครื่อง):
  ```
  schtasks /Create /SC MONTHLY /D 1 /ST 03:00 /TN "EDMS Integrity" /TR "C:\xampp\php\php.exe C:\xampp\htdocs\Website-SDU\tools\integrity_check.php"
  ```
- **ความเร็วค้นหา**: XAMPP ตั้ง `innodb_buffer_pool_size=16M` ซึ่งเล็กมาก แนะนำปรับใน `C:\xampp\mysql\bin\my.ini` เป็น `512M` แล้วรีสตาร์ต MySQL
- **อ่านข้อความไฟล์ย้อนหลัง**: `php tools/extract_text.php --all`
- **ลืมรหัสผ่านผู้ดูแล**: `php tools/reset_password.php <ชื่อผู้ใช้>` (รันบนเซิร์ฟเวอร์เท่านั้น)

### 10.2 การตรวจสิทธิ์และความปลอดภัยฝั่งโค้ด
- ทุก endpoint ใน `/api` เรียก `requireLogin()` (ตรวจ session + CSRF token ในหัว `X-CSRF-Token` ทุกคำขอที่ไม่ใช่ GET) ยกเว้น `agent.php` ที่ใช้ Bearer token ของเครื่องสแกน
- สิทธิ์ตามบทบาท (`isAdmin()`, `canEdit()`) และตามแฟ้ม (`folderScopeSql()`) ตรวจที่ฝั่งเซิร์ฟเวอร์ทุกครั้ง
- `api/file.php` เป็นด่านเดียวที่ส่งไฟล์ (โฟลเดอร์ `uploads/` เปิดตรง ๆ ไม่ได้) ตรวจแฟ้ม ถังขยะ ป้าย PDPA และสิทธิ์ดาวน์โหลด แล้วใส่ลายน้ำ/เซ็นซ้ำ
- ประทับ QR (FPDI + php-qrcode), ลายน้ำ และลายมือชื่อ (TCPDF) อยู่ที่ `config/storage.php` และ `config/docsign.php`
- รหัสผ่านเก็บแบบ bcrypt · Token เครื่องสแกนและลิงก์ผู้ตรวจเก็บเป็นแฮช SHA-256 · ลิงก์ผู้ตรวจเป็นเลขสุ่ม 192 บิต · session เก็บในตาราง `sessions` (ระบุอุปกรณ์/IP) · ล็อกบัญชีเมื่อรหัสผิด 5 ครั้ง · บันทึก audit log พร้อม IP

### 10.3 ฐานข้อมูล
ติดตั้งจาก `config/schema.sql` และอัปเกรดด้วย `config/migrate.php` / `migrate_v5.php` (เพิ่มอย่างเดียว) ตารางหลัก:
- **เอกสาร:** `documents`, `document_files` (SHA-256, เวอร์ชัน), `document_search`, `doc_sequences`, `folders`, `folder_permissions`, `prefixes`, `custom_fields`
- **ผู้ใช้/ความปลอดภัย:** `users` (บทบาท admin/staff/viewer, ข้อมูล 2FA), `sessions`, `api_tokens`, `audit_logs`, `system_settings`
- **สแกน:** `scan_jobs`, `scan_profiles`, `inbox_files`
- **ต้นฉบับกระดาษ:** `locations`, `loans`
- **ค้นหา/เชื่อมโยง:** `saved_searches`, `document_links`
- **ผู้ตรวจสอบ:** `share_links`, `share_link_docs`
- **ระเบียบสารบรรณ:** `destruction_batches`, `destruction_items`
- **ตรวจไฟล์:** `integrity_runs`
- `legacy_documents` / `legacy_folders`: ข้อมูลที่นำเข้าจากระบบเดิม (ถ้ามี)
